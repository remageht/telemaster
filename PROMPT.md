# Промпт: проект «ТЕЛЕМАСТЕР»

Скопируй всё ниже в новую сессию, чтобы продолжить с того же места.

---

Делаем одностраничный сайт-витрину магазина электро- и радиокомпонентов
«ТЕЛЕМАСТЕР» (доставка только по Крыму). Чистый HTML/CSS/JS без сборки
и зависимостей, полностью статический (запуск: `py -m http.server 8080`,
затем http://localhost:8080). Палитра: белый + тёплый беж + фирменный
красный `#c8102e` + янтарь `#ffb829` для тёмных сцен. Шрифты: Manrope
(интерфейс), Lora (заголовки, кириллица), системный моноширинный (артикулы,
метки). Две темы: светлая и Dala (Dala = тёмная, `[data-theme="dala"]`,
void #000, iris #8052ff), выбор в `tm-theme`. Выделение янтарное,
фавикон и theme-color меняются с темой. Фокус — фиолетовый в обеих темах.

## Структура

- `index.html` — лендинг (hero с 3D-лампой обычного размера в правом верхнем углу каркас из частиц с линиями-связями: стекло ледяные, цоколь стальные, нить тёплая; клик гасит/зажигает; скорость пружин ограничена (VM 520), клик подкручивает мягко с потолком 2.2 рад/с, свободных частиц у лампы нет (все на каркасе), якорные частицы не телепортируются через край — «хаос» исключён; статичное свечение-пятно убрано, светит только нить и
  автоматом слева внизу, полоса категорий, промо, каталог, void-полоса,
  хиты, преимущества + Крым-созвездие, отзывы, FAQ, контакты, футер),
  прелоадер «в мозг впаивают чип» (SMIL), модалка входа,
  `<main id="pageMain">` под динамические страницы, PWA-манифест,
  OG/Twitter-мета.
- `css/style.css` — все стили, адаптив, анимации, тёмная тема
  (`.hero__bulb` — full-bleed `inset:0`, `z-index:0`, свечение `::after`
  слева внизу; `.cat-resval` — плашка номинала резистора; `.promo-row`).
- `js/data.js` — каталог: 6+ категорий, 30 позиций формата
  `{id, name, sku, price, oldPrice?, stock, desc?, img?, imgs?[]}`.
  Свои иллюстрации — `ART` (21 SVG), фото — `img/` или URL. При бэкенде
  заменяется на API.
- `js/main.js` — один IIFE: роутер, корзина, избранное, кабинет, оформление
  (+промокод: поле `#promoInput`, кнопка `#promoApply`, строка `#promoLine`),
  отзывы, админка (вкладки, включая «Промокоды»: форма `#adminPromoForm`,
  `data-promo-toggle`, `data-promo-del`; настройки Telegram + кнопка
  `[data-tg-test]`), тосты `showToast()`, проверка обновлений.
- `js/circuit-bg.js` — фон «печатная плата»: параллакс, свечение за курсором,
  залп сигналов по клику, скролл разгоняет сигналы.
- `js/constellation.js` — движок Dala-созвездий `createField`, единый шаблон:
  `DALA = ["#8052ff","#ffb829","#ffffff","#e879f9","#40c4ff","#15846e"]`
  во всех сценах; мелкая плотная частица (3D: 260 шт, 1.6–3.4).
  API поля: `{ setAwake, setup, setModel, configure, refresh }`, реестр
  `liveFields`. Замер по rect **канваса** с фолбэком на родителя; `setup`
  один раз + при дрейфе размеров (`sizeDrifted`, допуск 2px); после
  `document.fonts.ready` все поля пересобираются. Опции: `bulbScale`
  (hero-лампа 1.0 → 430 частиц; гигантская 1.5 отклонена пользователем), `bx`/`by` (сдвиг центра, hero 0.12/0.8),
  `drift` (hero 0 — лампа привязана к точке, иначе статичное свечение отстаёт; включать только вместе со следящим свечением), `spinRate` (лампа 0.05), `toggleLit`, `shockwave`
  (у лампы ВЫКЛЮЧЕН — клик только гасит/зажигает нить).
  3D-фигуры (чип, резистор, паяльник, LED, конденсатор, мультиметр, тороид,
  ТВ) с физикой пружин, расселены по сайту (`data-model3d`,
  `__modelsRefresh`); резистор живой: `BAND_COLORS`, `o.bands=[d1,d2,mult]`,
  клик = случайный номинал E12 через `wireResistorLab` + подпись
  `[data-resval]`; 2D-фигуры (`shape:"bulb"`, `shape:"crimea"` — контур
  Крыма 42 точки в блоке доставки).
- `js/pcb-field.js` — фон void-полосы: чип и расходящиеся дорожки
  с импульсами.
- `sw.js` + `manifest.json` + `img/icon-*.png` — PWA и офлайн.
  `robots.txt`, `sitemap.xml` — в корне.
- Версии в `?v=` (main v59, css v61, constellation v38, data v2,
  circuit-bg v6, pcb-field v1), дублировать в ASSETS `sw.js`
  (CACHE `tm-v79`) и сюда. SW сам перезагружает страницу при обновлении (один раз за сессию, флаг tm-sw-claimed);
  сайт проверяет BUILD и показывает тост «Обновить».
  Reveal скрывает контент только при живом JS (класс `js`). SW: HTML — всегда сеть (офлайн-фолбэк), ассеты с ?v= — cache-first; install с cache:"reload" и register с updateViaCache:"none" — HTTP-кэш больше не подкладывает старый HTML (был вечный цикл обновления).

## Роуты (hash)

`#/` (лендинг), `#/catalog` (сетка/таблица, фильтр, сортировка),
`#/category/<id>` (в шапке 3D-фигура; у passive — живой резистор),
`#/product/<id>` (галерея, характеристики, отзывы, аналоги, шаринг),
`#/search/<запрос>`, `#/cart` (опт −25% от 10 шт),
`#/checkout` (самовывоз 0 / курьер 490 / по Крыму 350, от 3000 ₽ бесплатно;
промокод вычитается до доставки), `#/cabinet` (трекинг, прогресс скидки 5%
с 3-го заказа, избранное, история с повтором, просмотренные),
`#/admin` (пароль `telemaster2026`, только демо!), остальное — 404.
Title вкладки ставится под страницу.

`lines`, полями `discount`/`promo`), `tm-fav`, `tm-leads`, `tm-reviews`

оплата, SMS, OAuth).

## Стиль работы

Маленькие шаги, один отчёт на шаг, русский язык. После правок поднять `?v=`,
CACHE в `sw.js` и версии здесь. Проверять:
`Invoke-WebRequest http://localhost:8080/`. Опасные места: порядок
`?v=` и BUILD расходились и давали вечный тост — версия running-кода
читается из DOM. Не доверять неотлаженному коду из головы — сверять
фактический текст файлов перед правками. Headless-скриншоты в песочнице
ненадёжны (зомби-процессы chrome, виснущие шрифты без сети, RAF:0 —
кадры анимации вообще не крутятся) — чистить процессы через
`Get-Process chrome | Stop-Process -Force`, визуал подтверждать
у пользователя. Сервер поднимать отдельным процессом:
`Start-Process py -ArgumentList "-m","http.server","8080"
-WorkingDirectory <telemaster> -WindowStyle Hidden`
(фоновые Job умирают вместе с сессией shell).
